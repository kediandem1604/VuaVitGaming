# Mượt hơn — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tải nhanh hơn (cache, tách chunk, tải trước, giữ dữ liệu cũ, khung xương, cập nhật lạc quan) và một bộ chuyển động thống nhất.

**Architecture:** Server chỉ đổi header cache file tĩnh. Web: route lazy + chunk vendor (Vite), helper prefetch dùng chung, `Skeleton` + `QueryState` mới, thông số chuyển động là CSS custom properties áp cho mọi chỗ.

**Tech Stack:** Fastify 5 + `@fastify/static`, React 19, React Router 7, TanStack Query 5, Vite 6, Tailwind 4, Vitest 3.

**Spec:** `docs/superpowers/specs/2026-10-28-smooth-ui-design.md`

## Global Constraints

- Không thêm thư viện mới. Chỉ animate `transform`/`opacity`. `prefers-reduced-motion: reduce` tắt mọi chuyển động trừ mờ `--dur-fast`.
- Thông số: `--dur-fast 120ms`, `--dur-base 200ms`, `--dur-slow 320ms`, `--ease-out cubic-bezier(0.2,0,0,1)`, `--ease-in cubic-bezier(0.4,0,1,1)`, `--ease-spring cubic-bezier(0.34,1.4,0.64,1)`.
- Web test DB-free `npx vitest run --project web`; server test `GGD_TEST_DB=embedded`, một lượt mỗi lúc. Docker hỏng — không đụng. Không đụng `.env`. Comment tiếng Việt.
- Khoá query dùng chung ở `src/web/lib/queryKeys.ts`; không import trang từ trang khác.
- Commit kết thúc bằng dòng trống + `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Route lazy + View Transitions: điều hướng nhanh liên tiếp hoặc nút Back không để trang trắng/kẹt hiệu ứng (Task 3).
2. `keepPreviousData` khi đổi sang mùa chưa có dữ liệu: bảng cũ không bị hiểu nhầm là dữ liệu mùa mới (phải có trạng thái bận rõ ràng, tiêu đề mùa đổi ngay) (Task 2).
3. Cập nhật lạc quan Tham gia khi buổi đã đầy/đã đóng → trả lại đúng và báo lỗi (Task 2).
4. Bản deploy mới: `index.html` không bị cache nên luôn trỏ tới chunk mới; chunk cũ bị xoá không làm trang lỗi khi người dùng đang mở bản cũ (lazy import lỗi → tải lại trang một lần) (Task 1/2).
5. Giảm chuyển động bật → không còn chuyển động nào ngoài mờ nhanh (Task 3).
