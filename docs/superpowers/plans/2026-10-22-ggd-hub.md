# GGD Hub — Kế hoạch triển khai

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây GGD Hub — web + bot Discord quản lý thành viên, buổi chơi, nhắc giờ, vote MVP và bảng xếp hạng role cho một server Goose Goose Duck.

**Architecture:** Một tiến trình Node.js chạy Fastify (API + phục vụ web React đã build), bot discord.js và bộ hẹn giờ 60 giây, dùng chung PostgreSQL qua Prisma. Logic nghiệp vụ nằm trong service thuần nhận `Ctx` (db, mailer, notifier, directory, đồng hồ, config); bot và API chỉ là lớp vỏ gọi service. Discord và email đi qua cổng (interface) để test bằng bản giả.

**Tech Stack:** Node 24, TypeScript 5 (strict, ESM), Fastify 5, discord.js 14, Prisma 6 + PostgreSQL 16, React 19 + Vite 6 + React Router 7 + TanStack Query 5 + Tailwind CSS 4, Nodemailer 6, zod 3, Vitest 3 (+ jsdom, Testing Library cho web), tsx.

**Spec:** `docs/superpowers/specs/2026-10-22-ggd-hub-design.md` — đọc kèm. Kế hoạch này không lặp lại bảng role (§6) và luật nghiệp vụ; khi bước nào ghi "theo spec §x" thì giá trị chính xác nằm ở đó.

## Global Constraints

- Một `package.json` ở gốc, npm, không workspace. `"type": "module"`. Code server dùng `module: NodeNext` → import tương đối phải có đuôi `.js`.
- Cấu trúc: `src/server/**` (backend + bot), `src/web/**` (React, Vite root), `src/shared/**` (kiểu DTO dùng chung), `tests/server/**`, `tests/web/**`, `prisma/`.
- Mọi chữ người dùng thấy (web, Discord, email, thông báo lỗi) là tiếng Việt có dấu. Lỗi trả về không lộ stack/chi tiết nội bộ.
- Thời gian lưu UTC. Giờ Việt Nam = UTC+7 cố định (không có giờ mùa hè). **Chỉ** `src/server/lib/time.ts` được làm toán múi giờ; nơi khác gọi hàm của nó.
- Ngày-không-giờ (`played_on`) đi qua API dưới dạng chuỗi `YYYY-MM-DD`; lưu cột `@db.Date`.
- Mã thành viên: `GGD-` + số từ sequence `member_code_seq`, đệm 4 chữ số (`GGD-0001`; quá 9999 thì để nguyên, vd `GGD-10000`).
- Không xoá cứng `members` hay `stat_reports`.
- Bí mật chỉ đọc từ biến môi trường (spec §11).
- Màu phe: Ngỗng `#2F80ED`, Vịt `#E5484D`, Phe thứ 3 `#8E4EC6`.
- Discord custom ID: `att:join:<sessionId>`, `att:leave:<sessionId>`, `vote:<roundId>:<categoryId>`.
- Test chạy trên PostgreSQL thật: `docker compose up -d db` → DB `ggd_test` tại `postgresql://ggd:ggd@localhost:54329/ggd_test`. Test server chạy tuần tự (một DB). Mỗi test gọi `resetDb()` (xoá dữ liệu + nạp lại dữ liệu mẫu).
- Mỗi task kết thúc bằng một commit; thông điệp kiểu `feat: ...` / `test: ...`, dòng cuối `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Bấm "Tham gia" cùng lúc khi buổi sắp đủ người** (Discord và web gần như đồng thời) → số người tham gia không bao giờ vượt sức chứa; người thừa nhận "Đã đủ người". Test: Task 8 `concurrent joins never exceed capacity`.
2. **Thành viên chưa từng đăng nhập web** (email null) nhưng `notify_email = true` → chỉ nhận DM, không có dòng log email lỗi. Test: Task 10 `member without email only gets DM`.
3. **Discord sập lúc tạo buổi hoặc mở vote** → dữ liệu vẫn lưu, tin Discord được bộ hẹn giờ đăng bù, vote vẫn bấm được sau đó. Test: Task 8 `create while Discord down marks dirty`, Task 11 `retry clears dirty`, Task 12 `vote messages published later`.
4. **Trận chơi ngày cuối tháng, được duyệt đầu tháng sau** → điểm tính cho mùa cũ, thông báo hoá thân ghi mùa cũ; sau giờ chốt thì khai bù cho mùa cũ bị từ chối. Test: Task 16 `report played Oct 31 approved Nov 2 counts for 2026-10`, Task 17 `late report for a closed month is refused`.
5. **Buổi kết thúc mà không ai tham gia** (kể cả tự kết thúc) → buổi chuyển `ended`, không mở vote, không gọi Discord với menu rỗng (Discord từ chối menu 0 lựa chọn). Test: Task 12 `ending a session with no attendees opens no round`.
