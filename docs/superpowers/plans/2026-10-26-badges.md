# Huy hiệu (danh hiệu vĩnh viễn) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Members earn permanent public titles — seven monthly titles (SMVP, Vua tấu hài, three faction tops, Chăm cày, Đa diện) and nine lifetime milestones — shown on a new Huy hiệu page and a new public member page.

**Architecture:** A shared catalogue (`src/shared/badges.ts`) defines every badge. A scheduler job (`badges`) awards finished months once (guarded by a `badge_months` row) and grants milestones every tick, writing frozen rows to `member_badges` that are never updated or deleted. Read-only routes feed the web pages; Discord gets a durable monthly summary and best-effort milestone lines.

**Tech Stack:** Node 24, Fastify 5, discord.js 14 (behind the `DiscordNotifier` port), Prisma 6 / PostgreSQL 16, React 19 / TanStack Query / React Router 7 / Tailwind 4, Vitest 3.

**Spec:** `docs/superpowers/specs/2026-10-26-badges-design.md` (binding; read §3–§10).

## Global Constraints

- All user-facing text Vietnamese with diacritics; code comments Vietnamese; files LF.
- Commit messages English, ending with a blank line then exactly `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Tests on real PostgreSQL: `GGD_TEST_DB=embedded` (Docker Desktop is broken on this PC — never try to repair it). Full suite once per task before committing; `npm run typecheck`; `npm run build` in the last task.
- Time zone math only through `src/server/lib/time.ts` (UTC+7): `toVnDate`, `seasonIdOf`, `seasonDateRange`, `seasonCloseAt`, `formatSeasonLabel` ("MM/YYYY"), `previousSeasonId`.
- `member_badges` rows are never updated or deleted by app code.
- Badge-group mapping by exact category name: `Giết nhiều nhất`, `Ngỗng chạy giỏi nhất` → `mvp`; `Pha xử lý ngu nhất`, `Pha dí người ngu nhất`, `Pha đẻ trứng lộ liễu nhất (Cò gáy)`, `Pha chém lố nhất (Kiếm sĩ)` → `fun`; others `none`.
- Monthly title text: `{name} tháng {MM}/{YYYY}`; milestone title text: `{name}`.
- Thresholds: `smvp`, `fun_king`, `grinder` ≥ 1; `versatile` ≥ 2 roles; faction tops: points > 0. Ties share the title except faction tops (rank 1 of `getFactionTop(ctx, M, 1)`).
- Milestones: games 10/50/100; MVP 1/10/50 (group `mvp` only); incarnate 1 and 5 distinct roles (`role_titles`); director = an **approved** report with `highlight_message_id` not null.
- Discord text: names escaped for Markdown; announcements never ping anyone.
- App setting key `badges.milestones_backfilled` (ISO time) marks the silent first milestone pass.
- Every new HTTP route requires login (`requireMember`).

## Review Focus

- A session starting 00:30 VN on the 1st (17:30 UTC the day before) counts for the new month; one at 23:30 VN on the last day counts for that month — test in Task 2.
- A month with MVP awards but no `seasons` row is still awarded; a month whose `seasons` row is not yet closed waits — test in Task 2.
- Two workers (or a re-run) never double-award a month; a Discord failure keeps `announce_pending` and the next tick retries — test in Task 2.
- The first milestone pass is silent, later passes announce only newly created rows; members who left still receive milestones — test in Task 3.
- The public member page never exposes email, Discord id or access level; paging stays stable when many rows share one `awardedAt` (all grants of a month do) — test in Task 4.
