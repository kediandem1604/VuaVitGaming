# Treo thưởng — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mod/admin treo thưởng theo buổi; người chơi nhận trên web/Discord; mod duyệt; điểm vào bảng xếp hạng.

**Architecture:** Hai bảng mới `bounties`, `bounty_claims`; module server `src/server/modules/bounties/` (quản lý mục, nhận, duyệt); điểm gộp vào `aggregateSeason` (stats/leaderboard.ts) và tổng phe; Discord theo mẫu tin buổi chơi (cờ dirty + bộ hẹn giờ); web theo mẫu các tab/trang có sẵn.

**Tech Stack:** Fastify 5, discord.js 14, Prisma 6 / PostgreSQL 16, React 19 + TanStack Query, Vitest 3.

**Spec:** `docs/superpowers/specs/2026-10-29-bounties-design.md` (nguồn chuẩn cho mọi chữ, giá trị, luật).

## Review Focus

1. Hai người bấm "Tôi đã hoàn thành" cùng mục cùng buổi qua web và Discord gần như cùng lúc (cùng người) → đúng một lần nhận, lần kia báo "đã nhận rồi" (Task 2).
2. Duyệt lần nhận đúng lúc chốt mùa → hoặc tính vào `role_titles`, hoặc bị từ chối "Mùa đã chốt" — không lệch (Task 2).
